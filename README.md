 🚀 LearnHub

A modern learning platform designed to help students and developers learn, practice, and grow their careers—all in one place.

 🌟 About

LearnHub is an all-in-one educational platform that provides curated learning resources, coding practice opportunities, hackathons, quizzes, internship recommendations, and career guidance.

The goal is to eliminate the need to visit multiple websites by bringing everything together under a single platform.

> ⚠️ **Project Status:** Currently under active development. Only the Home Page has been completed. More features will be added in future updates.
